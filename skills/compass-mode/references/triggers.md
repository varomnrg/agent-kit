# Principle triggers

Use this index to decide which detailed entries in `principles.md` could change
the task. No trigger means no principle citation is required.

| Trigger | Principle |
|---|---|
| Diff sizing, new layer, or obsolete structure | Smallest sufficient change |
| Stateful logic, repeated shape assumptions, or unclear ownership | Foundational model |
| A new requirement invalidates a foundational assumption | Coherent redesign |
| Understanding requires tracing layers or hidden mutable state | Reader locality |
| Controlled migration has old and new internal paths | Target-state migration |
| External input, framework adapter, storage, network, or configuration | Boundary discipline |
| Retry, resume, reconcile, crash recovery, or partial execution | Idempotent operations |
| Multiple actors could write the same resource | Separate shared state |
| Two failed attempts share an assumption | Attack the premise |
| Bug, regression, failure, or completion claim | Root-cause proof |
| Writing or preserving tests | Behavioral contract |
| Sweep, migration, or multi-step delivery | Verifiable units |
| Benchmark, evaluation, latency, throughput, or other measured claim | Explain the measurement |
| Repeated manual step, recurring instruction, or high-risk check | Earn the mechanism |
| Novel and costly-to-reverse choice without useful precedent | Explore consequential alternatives |
